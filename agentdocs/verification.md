## 브라우저 확인

- 1440×900: 홈 첫 화면 확인. 프로젝트 섹션 시작 위치 y=900, 초기 화면에 프로젝트가 들어오지 않음. 가로 넘침 없음.
- 1024×800: 프로젝트 목록과 대표 미리보기 확인. App 필터 선택 시 Orbit만 표시되고 클릭으로 상세 이동.
- 768×1024: 홈·상세 확인. 상세 새로고침 후 본문 정상, 가로 넘침 없음.
- 375×812: 홈 첫 화면 확인. 프로젝트 시작 위치 y=812. 목록·Web 필터 동작 확인. 미리보기 텍스트 겹침을 수정하고 다시 확인.
- 키보드: Web 필터에서 Tab으로 App 필터 이동, solid 포커스 외곽선 확인.
- 프로젝트 상세에 실제 URL이 없는 실행·소스 버튼은 표시하지 않음.
- 기본 본문색 #263d31 / #f5f3ec 대비 약 10.54:1. 보조색은 프로젝트 배경에서 대비가 부족했던 #667268 대신 #5f6b61로 조정.

## 구현했으나 별도 실측하지 않은 항목

- reduced-motion CSS는 스크롤·전환·조형 애니메이션을 중지하도록 구현했다. OS 설정 변경을 통한 실제 동작 검증은 수행하지 않았다.
- 모든 인터랙션은 기본 링크·버튼을 사용하나 스크린리더 전체 탐색 및 모든 텍스트 색 조합 자동 감사는 미실행.
- Lighthouse 및 실사용 성능 측정, 실제 프로젝트 이미지 로딩 검증은 아직 미실행. 현재 프로젝트 미리보기는 CSS 도형으로 구성했다.
- GitHub Pages 공개 배포·원격 워크플로 실행은 아직 미실행.

실제 소개와 프로젝트 데이터를 받은 뒤 콘텐츠 줄바꿈, 이미지 비율, 외부 링크를 다시 검증한다.
