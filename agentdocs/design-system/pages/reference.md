# 메인 페이지 방향 시안

작성일: 2026-10-16. 이 문서는 확정 디자인 시스템이 아니라, 우주 도메인을 제외하기 위해 만든 비교용 레퍼런스 페이지의 기록이다.

## 사용자 요구

- 우주·위성·글로우를 메인 페이지에서 제외한다.
- 프로필 사진, 이름, 간단한 소개, `AI Engineer` 직업 표기를 첫 화면의 중심에 둔다.
- 흔한 AI 서비스 랜딩 페이지가 아닌, 디자이너 포트폴리오처럼 절제된 인상을 만든다.

## 구현한 세 방향

1. **The Monograph** — 따뜻한 적갈색과 큰 타이포를 사용한 에디토리얼 소개형. 이름과 인물 사진이 가장 먼저 읽힌다.
2. **Quiet Index** — 차분한 다크 배경, 세로 사진, 최소 내비게이션을 사용한 정제된 인덱스형.
3. **Open Studio** — 밝은 갤러리, 큰 사진과 짧은 소개를 병치한 이미지 중심형.

## 공통 원칙

- 장식용 별, 궤도, 위성, 기술적 수치, 과도한 그라디언트를 배제한다.
- 직업은 역할로만 표기하며 AI 관련 클리셰 이미지나 생성형 일러스트를 사용하지 않는다.
- 사진은 현재 구도 검증용 SVG 자리 표시자다. 실제 프로필 사진이 제공되면 `/public/images/profile-placeholder.svg`를 같은 세로 비율의 실제 파일로 교체한다.
- 링크는 키보드 포커스가 보이고, reduced-motion 환경에서 전환이 중지된다.

## 검증

- `pnpm build` 성공: Astro 진단 0 errors, 0 warnings.
- `/reference/`를 로컬 브라우저에서 열어 콘텐츠 구조와 작은 화면의 재배치를 확인했다.

다음 단계는 사용자가 세 방향 중 하나를 선택하거나 조합 지시를 준 뒤에만 실제 `/` 메인 페이지와 기존 우주 자산을 교체하는 것이다.
